# CYBERMYCELIUM — Нулевой узел

Короткая браузерная приключенческая игра с неподвижной кинематографичной камерой и управлением указателем. Проводник исследует два помещения живой вычислительной сети, восстанавливает маршрут сигнала и пробуждает узел памяти.

**Играть:** https://givscson.github.io/CYBERMYCELIUM/

## Управление

- Нажмите на участок пола, чтобы подойти к нему; нажмите на предмет, чтобы подойти и взаимодействовать.
- «Зрение сети» или клавиша `V` подсвечивает доступные предметы.
- WASD или стрелки двигают Проводника; `E` или Enter осматривает ближайший предмет. `V` включает зрение сети, `J` открывает журнал, Esc показывает меню.
- «Журнал» показывает найденные следы и состояние восстановления.
- Меню позволяет продолжить или начать заново. В настройках доступны скорость движения, размер текста, постоянная подсветка предметов и уменьшение анимации. Игра сохраняет прохождение и настройки в браузере. На телефоне удобнее горизонтальная ориентация.

## Запуск и проверка

Откройте `index.html` через локальный HTTP-сервер, например `python3 -m http.server 8000` из корня проекта. Сборка и внешние зависимости не нужны. Проверка сценария: `node tests/smoke.cjs`.

Фоны `assets/atrium.webp` и `assets/memory.webp` созданы специально для проекта. Развёртывание GitHub Pages описано в `.github/workflows/pages.yml`.

## История

В обеих сценах есть дополнительные следы: реестр основания и остаточный голос. Шесть записей постепенно открываются в журнале. В конце главы решение о внешнем сигнале сохраняется и меняет итоговую реплику. Рабочий канон и открытые вопросы собраны в [LORE.md](LORE.md).
