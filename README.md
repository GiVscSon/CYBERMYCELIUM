# CYBERMYCELIUM — Нулевой узел

Браузерная игровая сцена вселенной Кибермицелия. Откройте `index.html` или опубликованную GitHub Pages версию после развёртывания. Зависимостей и сборки нет.

Управление: A/D или стрелки — движение, Space/↑ — прыжок, V — Network Vision, E — терминал. На телефоне доступны экранные кнопки. Активация узла сохраняется в localStorage.

Фон `node-zero.jpg` — PRIMUS MYCELIUM в промышленной вычислительной камере. Персонаж, платформы, терминал и частицы нарисованы поверх фона. Это ранняя одна сцена, ещё без отдельных параллакс-слоёв и готового спрайта героя.

Для локального запуска: `python3 -m http.server 8000`, затем `http://localhost:8000`. Для воспроизводимого прогона логики: `node tests/smoke.cjs`. Результаты и ограничения описаны в `AUDIT.md`.
