# CYBERMYCELIUM — Нулевой узел

Первый играбельный web-прототип мира живой информации и растущей электроники. Откройте `index.html` в браузере. Зависимостей и сборки нет.

Управление: A/D или стрелки — движение, Space/↑ — прыжок, V — зрение сети, E — восстановить терминал. На телефоне есть экранные кнопки. Состояние узла сохраняется в localStorage.

`node-zero.jpg` — первый игровой фон: PRIMUS MYCELIUM в промышленной вычислительной камере. Камера перемещает видимую область изображения при движении героя. Игровая платформа, терминал и частицы нарисованы поверх фона. Это одна ранняя сцена, пока без отдельных слоёв параллакса и готового спрайта героя.
