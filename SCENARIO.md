# Сценарный порядок CYBERMYCELIUM

Карта мира: [WORLD_MAP.md](WORLD_MAP.md). Цельная концепция и сюжетные акты: [GAME_CONCEPT.md](GAME_CONCEPT.md). Обзорная интерактивная схема: [design/world-map.html](design/world-map.html).

1. Внешний предел и Склеп памяти (A1–A2) — реализовано.
2. Шов Разрыва (X) — реализовано.
3. Дальние боковые ветви (B0–B1 и C0–C1), третий носитель (T) — спроектировано, без новых игровых экранов.
4. Кольцо срастания (R) и сердцевина (H) — спроектировано, без новых игровых экранов.
5. Пролог прибытия (A0) — спроектирован так, чтобы не ломать существующие сохранения.

Следующее производство экранов начинается только после сверки каждого узла с картой, источниками сведений и последствиями выбора главы I.
